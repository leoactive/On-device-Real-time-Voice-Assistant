## 一、项目愿景

### 1.1 背景

在 AI 时代，我们习惯了与 ChatGPT、Claude 等大语言模型对话。但这些交互方式存在几个问题：

- **隐私风险**：所有对话数据都需要上传到云端
- **依赖网络**：没有网络就无法使用
- **缺乏实体感**：AI 只是一个屏幕里的对话框

### 1.2 愿景

**VoicePal** 是一个运行在本地的实时语音助手，它的核心理念是：

> **让 AI 真正"活"在你的电脑上，像一个私人助理一样与你对话**

我们追求：
- **本地化处理**：所有数据都在本地处理，隐私安全
- **实时响应**：按下按键即对话，像真人一样自然
- **自然交互**：语音输入、语音输出，形成完整闭环
- **持续运行**：后台监控，实时播报重要信息

## 二、核心特性

### 2.1 物理按键触发

不同于语音唤醒词（容易被误触发），我们采用**物理按键触发**机制：

- **按下 F16** → 开始录音
- **松开 F16** → 停止录音并处理
- 这种方式更可靠、更省资源、更适合桌面场景

### 2.2 完整的语音对话闭环

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   按键触发   │ ──▶ │  语音识别   │ ──▶ │   LLM 对话  │ ──▶ │  语音合成   │
│  (F16)      │     │   (ASR)    │     │  (Qwen3.5) │     │   (TTS)     │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
                            │                                           │
                            └─────────────────── 🔊 播放 ─────────────┘
```

### 2.3 本地 LLM 集成

通过 Ollama 集成强大的本地大语言模型：

- 支持 Ollama 所有模型（qwen3.5, llama3, mistral 等）
- 无需网络，本地推理
- 可以根据硬件配置选择不同规模的模型

### 2.4 实时监控与播报（规划中）

后台持续监控指定信息源，一旦有更新立即语音播报：

- 新闻监控
- 社交媒体动态
- 自定义关键词提醒

## 四、模型选型

### 4.1 语音识别 (ASR)

#### 选型结果：Fun-ASR Realtime

| 指标 | 数据 |
|------|------|
| **模型** | iic/funasr2.0_realtime |
| **中文准确率** | 93% |
| **延迟** | < 500ms |
| **特性** | 实时流式识别、31种语言、热词增强 |

#### 为什么选择 Fun-ASR？

1. **中文优化**：阿里通义实验室出品，对中文支持极佳
2. **实时性好**：流式识别，延迟低
3. **开源免费**：Apache 2.0 协议，可商用
4. **热词功能**：可自定义专业术语，提升识别准确率

#### 备选方案

- **Qwen3-ASR**：最新版本，中英文混合识别更准
- **WhisperKit**：Apple Silicon 原生优化

### 4.2 大语言模型 (LLM)

#### 选型结果：Ollama + Qwen3.5:9b

| 指标 | 数据 |
|------|------|
| **模型** | qwen3.5:9b |
| **大小** | 6.6 GB |
| **特点** | 中文能力强、推理速度快 |

#### 为什么选择 Ollama？

1. **本地运行**：无需网络，隐私安全
2. **模型丰富**：支持 llama3, qwen, mistral 等多种模型
3. **易于切换**：一行命令更换模型
4. **Mac 原生**：Apple Silicon 优化

#### 备选方案

- 本地 Transformers：需要更多配置
- 云端 API：需要网络

### 4.3 语音合成 (TTS)

#### 选型结果：Qwen3-TTS 0.6B

| 指标 | 数据 |
|------|------|
| **模型** | Qwen3-TTS-12Hz-0.6B-Base |
| **大小** | ~2.2 GB |
| **延迟** | 97ms（首包） |
| **特性** | 3秒克隆、10种语言、中文音色 |

#### 为什么选择 Qwen3-TTS？

1. **超低延迟**：97ms 首包延迟，接近实时
2. **中文友好**：专门针对中文优化
3. **声音克隆**：仅需 3 秒音频即可克隆声音
4. **开源免费**：Apache 2.0 协议

#### 备选方案

- **CosyVoice**：阿里开源，稳定性好
- **VALL-E**：微软开源，零样本克隆

### 4.4 模型组合推荐

| 场景 | ASR | LLM | TTS |
|------|-----|-----|-----|
| **平衡型** | Fun-ASR | qwen3.5:9b | Qwen3-TTS 0.6B |
| **高性能** | Qwen3-ASR | qwen3.5:35b | Qwen3-TTS 1.7B |
| **轻量级** | Fun-ASR-nano | qwen3.5:4b | Qwen3-TTS 0.6B |

## 五、快速开始

### 5.1 环境要求

- macOS 12.0+
- Apple Silicon (M1/M2/M3/M4) 或 Intel Mac
- 最低 8GB 内存（推荐 16GB+）
- conda 或 miniforge

### 5.2 安装步骤

#### 1. 克隆项目

```bash
git clone https://github.com/yourusername/voicepal.git
cd voicepal
```

#### 2. 创建 Python 环境

```bash
# 安装 miniforge（如果未安装）
brew install miniforge

# 创建环境
conda create -n voicepal python=3.12 -y
conda activate voicepal
```

#### 3. 安装依赖

```bash
# 基础依赖
pip install sounddevice numpy keyboard

# 深度学习
pip install torch torchvision torchaudio

# 语音处理
pip install transformers funasr
```

#### 4. 安装 Ollama

```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 下载模型
ollama pull qwen3.5:9b
```

### 5.3 运行

```bash
# 激活环境
conda activate voicepal

# 运行主程序
python main.py
```

### 5.4 使用方法

1. **启动程序**：运行 `python main.py`
2. **开始说话**：按住 **F16** 键（或 Fn+F16）
3. **停止录音**：松开按键
4. **等待处理**：系统自动识别、对话、播放
5. **退出**：按 `Ctrl + C`
